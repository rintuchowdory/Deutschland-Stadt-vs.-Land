# Deutschland: Stadt vs. Land

**Haben Menschen auf dem Land die gleichen Chancen wie in der Stadt?**

Live: https://rintuchowdory.github.io/Deutschland-Stadt-vs.-Land/

## Features
- 4 Seiten: Start, Dashboard, Vergleich, Karte
- 16 Regionen: 8 Städte + 8 Landkreise
- Fairness-Score: min-max normalisiert, 6 Dimensionen
- Radar-Chart, SVG-Karte, Bar-Chart Dashboard

## Tech Stack
React 18, Vite, Tailwind CSS, Recharts, GitHub Pages
